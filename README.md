# ปล้นพิพิธภัณฑ์ (Museum Heist)

เกมตอบคำถามทั้งห้อง ได้แรงบันดาลใจจากเกมขโมยทองใน Kahoot แต่ใช้ชื่อ ธีม ภาพ และกลไกของตัวเอง

## วงจรเกม
1. ตอบถูกได้เพชร 10 เม็ด, ตอบเร็วได้โบนัสสูงสุด +5, ถูกติดกันตั้งแต่ 3 ข้อได้ +5
2. ตอบถูกครบ 3 ข้อได้ตั๋วปล้น 1 ใบ (ถือได้สูงสุด 2 ใบ)
3. ใช้ตั๋วเลือกเป้าหมาย (ผู้นำ 3 คน + สุ่มอีกไม่เกิน 5 คน) แล้วงัดสลัก 3 ตัว (แตะตอนเข็มอยู่ในโซนเขียว, 9 วินาที)
   - 3/3 ขโมย 25%, 2/3 ขโมย 15%, 0–1 สัญญาณดัง (ตั๋วเสีย)
   - เป้าหมายมีล็อก: ล็อกถูกใช้ ตั๋วเสีย
   - คนที่เพิ่งโดนปล้นมีโล่ 25 วินาที
4. ล็อกตู้ราคา 20 เพชร กันได้ 1 ครั้ง

## อาชีพโจร
| อาชีพ | พลัง |
|---|---|
| 🧤 นักล้วงกระเป๋า | ขโมยได้ +5% |
| 🔐 นักเจาะตู้เซฟ | โซนเขียวกว้างขึ้น 1.9 เท่า |
| 🕵️ จอมวางแผน | เห็นว่าตู้ไหนติดล็อก |
| 🛡️ ผู้พิทักษ์ | เริ่มมีล็อก 1 อัน, โดนขโมยครึ่งเดียว |

ตัวเลขทั้งหมดอยู่ใน `js/rules.js` (TUNE)

## ไฟล์
- `host.html` + `js/host.js` จอครู (โปรเจคเตอร์) เป็นผู้ตัดสินเพชรทั้งหมด
- `play.html` + `js/player.js` มือถือนักเรียน
- `bank.html` + `js/bank.js` คลังคำถาม (localStorage key `cw-bank-v1` ใช้ร่วมกับเกมสงครามสีเมื่ออยู่บนโดเมน github.io เดียวกัน)
- `js/net.js` Firebase RTDB หรือโหมดทดลอง `?local=1`
- ข้อมูลอยู่ใต้ `mh/{code}` (แยกจาก `cw/` และ `rooms/`)

## ทดสอบในเครื่อง
`node dev-server.js` แล้วเปิด http://localhost:8323/host.html?local=1 และเปิด play.html หลายแท็บ
