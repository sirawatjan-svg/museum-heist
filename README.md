# ปล้นพิพิธภัณฑ์ (Museum Heist)

เกมตอบคำถามทั้งห้อง ได้แรงบันดาลใจจากเกมขโมยทองใน Kahoot แต่ใช้ชื่อ ธีม ภาพ และกลไกของตัวเอง

## วงจรเกม (ปรับ 21 พ.ย. 2569: นักเรียนแค่ตอบคำถาม ที่เหลือเกิดเอง)
1. ตอบถูกได้เพชร 10 เม็ด, ตอบเร็วได้โบนัสสูงสุด +5, ถูกติดกันตั้งแต่ 3 ข้อได้ +5
2. ตอบถูกสะสมครบทุก 3 ข้อ → หน้าปล้นเด้งเอง เลือกเป้าใน 6 วินาที (ไม่เลือก = สุ่ม)
   - งัดสลัก 2 ตัวภายใน 5 วินาที: 2/2 ขโมย 25%, 1/2 ขโมย 12%, 0 สัญญาณดัง
   - คนที่เพิ่งโดนปล้นมีโล่ 25 วินาที (ถ้าทุกคนมีโล่ รอบปล้นเก็บไว้ก่อน)
3. ตอบถูกสะสมครบทุก 9 ข้อ → สกิลอาชีพทำงานเอง + ภาพตัดฉากบนจอครู (ข้อ 9, 18, 27 ได้ทั้งสกิลและปล้น)
4. ไม่มีปุ่มล็อกตู้แล้ว (เด็กลืมกด)

## อาชีพโจร
| อาชีพ | พลังติดตัว | สกิล (ทุก 9 ข้อ) |
|---|---|---|
| 🧤 นักล้วงกระเป๋า | ขโมยได้ +5% | 👐 ล้วงหมู่: 8% จากผู้นำ 3 คน |
| 🔐 นักเจาะตู้เซฟ | โซนเขียวกว้าง 1.9 เท่า | 🗝️ กุญแจผี: ปล้นครั้งหน้าสำเร็จแน่ 35% |
| 🕵️ จอมวางแผน | งัดพลาดหมดก็ยังได้ 8% | 📂 ข้อมูลวงใน: 3 ข้อถัดไปเพชร ×2 |
| 🛡️ ผู้พิทักษ์ | โดนขโมยครึ่งเดียว | 🏦 ตู้นิรภัย: 45 วิ ปล้นไม่ได้ ใครมาปล้นเสียเพชร 10% ให้ |

ตัวเลขทั้งหมดอยู่ใน `js/rules.js` (TUNE)

## ไฟล์
- `host.html` + `js/host.js` จอครู (โปรเจคเตอร์) เป็นผู้ตัดสินเพชรทั้งหมด
- `play.html` + `js/player.js` มือถือนักเรียน
- `bank.html` + `js/bank.js` คลังคำถาม (localStorage key `cw-bank-v1` ใช้ร่วมกับเกมสงครามสีเมื่ออยู่บนโดเมน github.io เดียวกัน)
- `js/net.js` Firebase RTDB หรือโหมดทดลอง `?local=1`
- ข้อมูลอยู่ใต้ `mh/{code}` (แยกจาก `cw/` และ `rooms/`)

## ทดสอบในเครื่อง
`node dev-server.js` แล้วเปิด http://localhost:8323/host.html?local=1 และเปิด play.html หลายแท็บ
